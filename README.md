# DATA 607 — Week 7: HTML and JSON

## Project Overview

This project explores how HTML and JSON can be used to
organize and exchange structured data.

The dataset contains bibliographic information from
three electrical power system analysis books.

The project demonstrates how to import HTML and JSON
data into R and compare the resulting data frames.

## Project Objectives

- Collect information from three electrical engineering books.
- Organize the data in HTML and JSON formats.
- Import the files into R.
- Compare the resulting data frames.
- Validate data consistency.

## Dataset

The dataset contains three books and five variables:

- Title
- Authors
- Year
- Publisher
- ISBN

## Tools

- R
- RStudio
- Quarto
- HTML
- JSON
- Google Books API (optional validation)
